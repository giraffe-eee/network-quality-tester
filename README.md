# 网络质量检测器

网络质量检测器是一款面向竞技网游的 Windows 桌面工具。它关注的不是“这条网络能跑多快”，而是它在真实对局压力下，能不能持续、稳定地把每一个实时数据包送到服务器并带回响应。

许多网络在测速时看起来带宽充足、平均延迟也不错，但进入团战、多人语音或高频操作场景后，仍可能出现技能延迟、角色瞬移、短暂卡顿和掉线。问题通常不是平均网速，而是短时拥塞、无线重传、移动网络切换和尾部延迟。这个项目就是为发现这些问题而设计的。

## 它模拟什么

一次检测会在同一个连续窗口内并行维持游戏 UDP 数据、背景 UDP 压力和 TCP 回显，而不是把它们拆成互不影响的单项测试。

| 项目 | 模拟方式 | 用途 |
| --- | --- | --- |
| 游戏 UDP | `120pps`，常规载荷 `40-300B` | 模拟实时同步、移动与操作指令。 |
| 事件包 | 每 24 个游戏包插入一个 `1KB` 包 | 模拟团战、状态同步或事件密集时的突发数据。 |
| UDP 压力 | 约 `3Mbps/方向` 的完整回显 | 检查链路在实际占用下是否出现拥塞、丢包和排队。 |
| TCP 回显 | 与 UDP 压力同时运行 | 观察可靠连接在游戏流量存在时是否仍稳定。 |

因此，检测到的是从当前电脑到检测端点的整条网络路径，能够反映本地 Wi-Fi、网线、路由器、热点、基站、运营商线路与服务端之间共同造成的体验。

## 为什么比普通测速更有参考价值

普通测速主要回答下载、上传和平均延迟是否正常。它无法很好地说明：当游戏持续发包时，是否会突然几十毫秒没有回包；少量数据包是否会连续丢失；或者平均延迟很低但偶发延迟已经冲到数百毫秒。

网络质量检测器会特别关注这些会直接影响对局体验的数据：

- 游戏 UDP 丢包、连续丢包和最长回包空档
- 压力下的有效双向吞吐与压力包丢包
- P95、P99 尾延迟，而不只看平均延迟
- 持续抖动与突发抖动
- TCP 回显超时和稳定性

只有在持续负载下仍然低丢包、低抖动、低尾延迟并保持足够双向吞吐的网络，才会获得高分。

## 分数如何理解

评分中 UDP 占 70 分，TCP 占 30 分。UDP 更重要，是因为绝大多数竞技网游的实时操作与状态同步都依赖 UDP；TCP 用于衡量可靠连接在并发负载下是否也存在不稳定因素。

| 分数 | 含义 |
| --- | --- |
| 90 分以上 | 重度负载下仍保持稳定，适合竞技对局。 |
| 75-89 分 | 可以游戏，但高峰时段、团战或多人语音时仍可能感到波动。 |
| 60-74 分 | 压力下存在较明显的不稳定，不适合依赖实时操作的对局。 |
| 60 分以下 | 丢包、长回包空档或尾延迟问题突出，建议先改善网络环境。 |

评分不会因为一个固定阈值突然跳变。少量压力丢包、双向吞吐未达标、P95/P99 延迟升高或回包空档变长，都会持续降低分数。高分代表的是“负载下也稳定”，而不是只代表某一次平均延迟很低。

## 什么时候适合使用

- 排位、比赛或重要开黑前，比较有线、Wi-Fi 和手机热点的实际差异。
- 怀疑宽带测速正常但游戏仍卡顿时，定位是否存在尾延迟、瞬时丢包或回包空档。
- 更换路由器位置、Wi-Fi 频段、运营商线路或热点后，比较优化是否真正改善了游戏链路。
- 使用移动网络时，选择严格模式观察更长时间内的信号波动和基站切换风险。

## 测试模式

| 模式 | 时长 | 适合场景 |
| --- | ---: | --- |
| 快速 | 30 秒 | 快速确认当前网络是否存在明显问题。 |
| 正常 | 60 秒 | 默认模式，兼顾判断可靠性与测试流量。 |
| 严格 | 120 秒 | 用于 Wi-Fi、手机热点和间歇性卡顿的深入检查。 |

三种模式都使用相同的游戏负载模型；时长越长，越容易捕捉偶发波动。移动网络环境下请留意测试流量消耗。
