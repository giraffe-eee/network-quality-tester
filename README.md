# 网络质量检测器

用于检测网络连接质量的 Windows 桌面工具。

## 功能

- 进行网络质量检测并显示进度
- 生成检测结果报告
- 使用上海的公共测试节点进行测试

## 设计初衷

本工具面向游戏，尤其是网络对战与晋级赛等对连接稳定性要求较高的场景。

市面上多数网络检测工具侧重于下载、上传速率，但带宽正常并不代表游戏连接稳定。高延迟、瞬时丢包和网络波动都可能导致卡顿、掉线或操作延迟，且不一定能通过常规测速准确反映。

网络质量检测器通过连接质量检测，帮助玩家在重要对局前提前了解当前网络状态，并据此判断是否适合进行网络游戏。

## 使用方法

1. 下载 Release 中的 `网络质量检测器.exe`
2. 双击运行程序
3. 点击“开始检测”
4. 检测完成后查看或保存报告

## 说明

检测结果会受到本地网络、运营商线路和测试节点状态的影响，仅供参考。
